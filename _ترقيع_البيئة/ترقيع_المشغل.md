# ترقيعُ المشغِّل — ليستجيبَ نظامُ التشغيلِ لبرنامجِ فاضل

**الغاية (بنصِّ فاضل 5 تشرين الأوّل 2026):** «اريد ان يستطيع المبرمج كتابة برنامج بلغة فاضل وينفذ ويستخدم كما تعمل لغات البرمجة الاخرى».

**الآليّة:** لا نظامَ تشغيلٍ ينفّذُ بايثونَ — ينفّذُ `python.exe` وهو يقرأُ الملفّ. فالمطلوبُ **مشغِّلٌ مثبَّتٌ + ارتباطُ امتداد**، والمشغِّلُ هنا هو البيئةُ نفسُها مثبَّتةً.

**الموضع:** `لغة فاضل محدث\05_البيئة\فاضل_IDE.html` — **ملفُّ فاضل**. ⛔ لا يُمَسُّ إلّا بإذنِه.
**الحجم:** ثلاثُ كتلٍ · نحوُ خمسين سطراً · لا تُحذَفُ سطراً قائماً.
**اللغة:** جافاسكربت و JSON — **وهما لغةُ البيئةِ أصلاً** ⟹ صفرُ لغةٍ جديدة.

**وما بُنيَ خارجَ الملفِّ سلفاً (جاهزٌ ينتظرُ هذا الترقيع):**

```
downloads/فاضل/فاضل.webmanifest          ⟸ التثبيت + ارتباط «.فضل»
downloads/فاضل/فاضل_sw.js                ⟸ العمل بلا انترنت
downloads/فاضل/فاضل-192.png · -512 · -maskable-512
```

## الكتلة ① — في الرأس، قبلَ `</head>`

```html
    <link rel="manifest" href="%D9%81%D8%A7%D8%B6%D9%84.webmanifest">
```

**سطرٌ واحد.** و`<meta name="theme-color">` موجودٌ سلفاً فلا يُكرَّر.

## الكتلة ② — تسجيلُ العاملِ الخدميّ

تُوضَعُ في آخرِ أيِّ `<script>` — والأنسبُ بعدَ `setTimeout(() => checkForUpdate(true), 3000);`

```javascript
/* ═══ المشغِّلُ ① : العملُ بلا انترنت بعدَ التثبيت ═══ */
if ('serviceWorker' in navigator && location.protocol.startsWith('http')) {
    addEventListener('load', () => {
        navigator.serviceWorker
            .register('%D9%81%D8%A7%D8%B6%D9%84_sw.js')
            .catch(() => { /* يعملُ بلا عاملٍ خدميٍّ ايضا */ });
    });
}
```

**⚠ `location.protocol.startsWith('http')` ضروريٌّ:** فالبيئةُ تُفتَحُ أيضاً بـ`file://` بعدَ التنزيل، والعاملُ الخدميُّ يصرخُ هناك.

## الكتلة ③ — النقرةُ المزدوجةُ على «برنامجي.فضل»

```javascript
/* ═══ المشغِّلُ ② : نقرتانِ على «برنامجي.فضل» ⟹ يُفتَحُ هنا ═══
   وتماما كما ينقرُ المبرمجُ على «.py» فيفتحَها بايثون.           */
if ('launchQueue' in window && 'files' in LaunchParams.prototype) {
    launchQueue.setConsumer(async (معاملات) => {
        if (!معاملات.files || !معاملات.files.length) return;
        const مقبض = معاملات.files[0];
        try {
            const ملف = await مقبض.getFile();
            editor.value = await ملف.text();
            updateEditor();
            ملف_الحالي = ملف.name;
            مقبض_الحالي = مقبض;          /* ⟸ فـ«حفظ» يكتبُ في الملفِّ نفسِه */
            toast('فُتِحَ: ' + ملف.name, 'info');
        } catch (ع) {
            toast('تعذّرَ فتحُ الملفِّ', 'error');
        }
    });
}
```

**⚖ ولماذا `مقبض_الحالي = مقبض`:** عندَكم هذا المتغيّرُ قائمٌ و`showSaveFilePicker` مستعمَلٌ. فبإسنادِ المقبضِ **يصيرُ «حفظ» يكتبُ في ملفِّ المستعمِلِ الأصليِّ بلا سؤال** — وهذا عينُ ما تفعلُه المحرِّراتُ الأخرى.

## الكتلة ④ — الجسرُ: مجلّدٌ حقيقيٌّ يقرؤه البرنامجُ ويكتبُ فيه

```javascript
/* ═══ الجسرُ ③ : مجلّدٌ على قرصِ المستعمِلِ ⟷ برنامجُ فاضل ═══
   فيقرأُ برنامجُك بياناتِه الحقيقيّةَ ويكتبُ نتيجتَه ملفّا حقيقيّا. */
let مجلّد_العمل = null;

async function اختر_مجلد_العمل() {
    if (!('showDirectoryPicker' in window)) {
        toast('اختيارُ المجلَّدِ يعملُ على كروم او ايدج على سطحِ المكتب', 'warn');
        return null;
    }
    try {
        مجلّد_العمل = await showDirectoryPicker({ mode: 'readwrite', id: 'فاضل' });
        toast('مجلَّدُ العملِ: ' + مجلّد_العمل.name, 'info');
    } catch (ع) { /* الغى المستعمِلُ */ }
    return مجلّد_العمل;
}

async function اقرأ_من_المجلد(اسم) {
    if (!مجلّد_العمل && !(await اختر_مجلد_العمل())) return null;
    const م = await مجلّد_العمل.getFileHandle(اسم);
    return new Uint8Array(await (await م.getFile()).arrayBuffer());
}

async function اكتب_في_المجلد(اسم, بايتات) {
    if (!مجلّد_العمل && !(await اختر_مجلد_العمل())) return false;
    const م = await مجلّد_العمل.getFileHandle(اسم, { create: true });
    const ك = await م.createWritable();
    await ك.write(بايتات);
    await ك.close();
    return true;
}
```

**وتُوصَلُ بالحديدِ لاحقاً** — المنفذُ التسلسليُّ `serial0-output-byte` موجودٌ وموصولٌ في المحاكي، فيكتبُ البرنامجُ طلبَه فيه وتقرؤه `اقرأ_من_المجلد`. **وهذه خطوةٌ ثانيةٌ تُصمَّمُ بعدَ أن يعملَ ما فوقَها.**

## حدودٌ تُقالُ قبلَ البناءِ لا بعدَه

| الميزة | أينَ تعمل |
|---|---|
| التثبيتُ والأيقونةُ والنافذةُ الخاصّة | كروم · إيدج · بريف — ويندوز ولينكس وماك |
| العملُ بلا انترنت | كلُّ المتصفّحاتِ الحديثة |
| **النقرةُ المزدوجةُ على `.فضل`** | **كروميوم على سطحِ المكتبِ وحدَه** |
| **مجلّدٌ حقيقيٌّ** | **كروميوم على سطحِ المكتبِ وحدَه** |

**وإيدجُ مثبَّتٌ مع ويندوزَ أصلاً** ⟹ فلا تنصيبَ على المستعمِلِ هناك. وعلى فايرفوكس وسفاري **تعملُ البيئةُ كما هي اليوم** — ينقصُها النقرةُ والمجلَّدُ لا أكثر.

**⚠ وواحدةٌ لم تُمتحَنْ بعد:** الامتدادُ `.فضل` عربيٌّ، **ولم أختبرْ قبولَ كروميومَ لامتدادٍ غيرِ لاتينيٍّ في `file_handlers`.** ⟹ يُمتحَنُ بتثبيتٍ واحدٍ حقيقيٍّ على ويندوز. فإن رُدَّ، فالبديلُ ختمُ فاضلَ على امتدادٍ ثانٍ، **ولا أختارُه من عندي.**

## ترتيبُ التنفيذ

3. الحرّاسُ الثلاثةُ ثمّ الدفع.
4. **امتحانٌ واحدٌ حقيقيٌّ على ويندوز**: افتحِ الصفحةَ بإيدج ⟹ «تثبيت» ⟹ أيقونةٌ في قائمةِ البدء ⟹ احفظْ ملفّاً `تجربة.فضل` ⟹ **انقرْ عليه نقرتَين.**
